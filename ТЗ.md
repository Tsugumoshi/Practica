# Техническое задание

## 1. Общие сведения

- **Наименование:** консольная программа «Сумма чётных чисел Фибоначчи».
- **Автор:** Абрамов И. С., гр. ИСП-31с.
- **Дисциплина:** ПМ.06 «Сопровождение информационных систем».
- **Период разработки:** 19.10.2026 – 31.10.2026.

## 2. Назначение

Вычисление суммы всех чётных элементов ряда Фибоначчи, не превышающих заданное пользователем значение.

## 3. Требования к функциональности

1. Ввод значения-ограничителя из консоли.
2. Ввод значения из текстового файла (аргумент `--input`).
3. Вывод результата в консоль или в файл (`--output`).
4. Обработка ошибок ввода (нечисловые значения, отрицательные числа).

## 4. Требования к надёжности

- Корректная работа при limit до 4 000 000.
- Валидация входных данных.
- Обработка исключений без аварийного завершения.
