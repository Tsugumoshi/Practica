# Тест-кейсы и результаты проверки

**Объект проверки:** программа «Сумма чётных чисел Фибоначчи» (`fibonacci_even_sum.py`) · **Основание:** задание учебной практики ПМ.06, вариант 1 · **Дата проверки:** 24.10.2026
**Среда:** Linux, Python 3.12.3. Консольные и файловые тест-кейсы выполнены реальным запуском программы; тест-кейсы графического интерфейса требуют ручной проверки (в среде проверки нет tkinter и экрана).

Подготовка: папка с `fibonacci_even_sum.py` открыта в терминале. Команды в таблицах записаны без префикса: `--console` означает `python fibonacci_even_sum.py --console`. Если не сказано иное, файл `in.txt` (UTF-8) содержит одну строку `100`, а файла `out.txt` в папке нет.

| ID | Шаги | Ожидаемый результат | Статус |

**Фактический результат TC-26:** программа завершается аварийно с traceback `EOFError: EOF when reading a line`. Причина: `read_limit_from_console()` перехватывает только `ValueError`. Рекомендуемое исправление: добавить в `except` исключения `EOFError` и `KeyboardInterrupt` с выводом «Ошибка: ввод прерван» и кодом 1.

**Итого:** 26 тест-кейсов: 16 пройдено, 1 провален, 9 (графический интерфейс) ожидают ручной проверки.

## 4. Ограничения проверки
- Проверка выполнена на Linux с Python 3.12. Запуск на Windows и macOS вручную не выполнялся.
- Тест-кейсы TC-17…TC-25 не выполнены: в среде проверки нет tkinter и графического экрана. Их нужно пройти вручную и заполнить статус.
- В файловом режиме тексты ошибок для `abc`, пустого файла, `12.5` и отсутствующего файла выводятся в виде технических сообщений Python (например, «invalid literal for int()…»). Формально требование «сообщение с “Ошибка:”» выполнено, но для пользователя текст неудобен.

## 5. Заключение
Расчёт, ввод через консоль и файловый ввод-вывод работают корректно: консольные и файловые тест-кейсы пройдены, автоматические тесты проходят (30 из 30). Выявлен один дефект (TC-26: аварийное завершение с traceback при закрытии ввода). Графический интерфейс требует ручной проверки по TC-17…TC-25.
