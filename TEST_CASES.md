# Тест-кейсы и результаты проверки

**Объект проверки:** программа «Сумма чётных чисел Фибоначчи» (`fibonacci_even_sum.py`) · **Основание:** задание учебной практики ПМ.06, вариант 1 · **Дата проверки:** 24.10.2026
**Среда:** Linux, Python 3.12.3. Консольные и файловые тест-кейсы выполнены реальным запуском программы; тест-кейсы графического интерфейса требуют ручной проверки (в среде проверки нет tkinter и экрана).

**Статусы:** Passed: пройден; Failed: провален; Blocked: выполнить не удалось (нет условий для проверки).

**Общие предусловия (ОП):** установлен Python 3.12; файл `fibonacci_even_sum.py` лежит в папке, которая открыта в терминале; файла `out.txt` в папке нет. Если не сказано иное, файл `in.txt` (UTF-8) содержит одну строку `100`.

## 4. Ограничения проверки
- Проверка выполнена на Linux с Python 3.12. Запуск на Windows и macOS вручную не выполнялся.
- Тест-кейсы TC-17…TC-25 имеют статус Blocked: в среде проверки нет tkinter и графического экрана. Их нужно пройти вручную и заполнить фактический результат и статус.
- В файловом режиме тексты ошибок для `abc`, пустого файла, `12.5` и отсутствующего файла выводятся в виде технических сообщений Python (например, «invalid literal for int()…»). Формально требование «сообщение с “Ошибка:”» выполнено, но для пользователя текст неудобен; рекомендуется заменить их понятными сообщениями.

## 5. Заключение
Расчёт, ввод через консоль и файловый ввод-вывод работают корректно: консольные и файловые тест-кейсы пройдены (16 Passed). Выявлен один дефект (TC-26: аварийное завершение с traceback при закрытии ввода). Графический интерфейс требует ручной проверки по TC-17…TC-25.
